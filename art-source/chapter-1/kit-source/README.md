## Catatan kualitas

- Strip `mountain-*`, `ocean-*` dan awan di paket masih membawa **label teks** nama file; skrip
  membuangnya. Jangan memakai file paket langsung di game.
- Aset `pohon/` beresolusi kecil (draft); pohon kelapa diperbesar ×1,25 di game sehingga sedikit lunak.
